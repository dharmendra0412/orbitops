# ORBITOPS — Post-MVP Backlog

Items below are intentionally deferred and must not expand the MVP critical path.

- Multiple lunar sites and player-editable mission durations.
- High-fidelity orbit propagation, SPICE-driven real-time geometry and terrain ray tracing.
- Validated thermal-state simulation, battery electrochemistry, radiation and detailed communications link closure.
- Live NASA/JPL API calls during gameplay.
- Dedicated worker, broker, Redis, microservices or horizontally scaled simulation.
- Production-scale matchmaking, persistent chat and presence history.
- Autonomous AI spacecraft design or AI-authored engineering results.
- Advanced reliability prediction based on flight-qualified hardware evidence.
- Cross-platform bitwise deterministic floating-point guarantees beyond the pinned runtime; retain tolerance-based comparisons for runtime upgrades.

These deferrals do not replace the human approval gates in `TECHNICAL_DECISIONS.md`.
